# ScreenShareIMESync Releases

이 저장소는 ScreenShareIMESync의 자동 업데이트 배포 전용입니다. 소스 코드는 여기에 없습니다.

## 처음 설치하기

1. [Releases](../../releases) 탭에서 최신 버전의 zip 파일을 내려받습니다.
2. 압축을 풀고 `ScreenShareIMESync.app`을 `/Applications`로 옮깁니다.
3. 처음 실행할 때 "확인되지 않은 개발자" 경고가 뜨면 Finder에서 앱을 우클릭 → 열기를 선택하고, 한 번 더 "열기"를 누릅니다.
4. 시스템 설정 > 개인정보 보호 및 보안 > 손쉬운 사용에서 ScreenShareIMESync를 허용합니다.
5. 이후 업데이트는 앱이 자동으로 확인·설치합니다.
